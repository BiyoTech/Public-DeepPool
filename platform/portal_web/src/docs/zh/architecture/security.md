# DeepNode 安全保障

## 概述

DeepPool 将 Prompt 数据安全视为平台的核心能力之一。当您的推理请求通过 DeepNode 节点处理时，我们通过**多层纵深防御体系**确保您的 Prompt 和业务数据在边缘设备上不会被窥探、篡改或泄漏。

本文面向 API 调用方（Consumer），说明 DeepNode 的安全防护能力以及由此带来的使用须知。

---

## 数据安全防护能力

### 🔒 推理代码防篡改

DeepNode 的推理引擎代码在构建时经过**编译保护**处理，节点运营者无法直接查看或修改推理过程中的源代码。即使攻击者拥有设备的管理员权限，也无法通过简单编辑来植入数据窃取逻辑。

### 🔒 运行时完整性校验

每个 DeepNode 安装包在构建时生成唯一的**完整性指纹**。启动时和运行过程中，DeepNode 会持续验证所有关键组件是否被修改。一旦检测到任何篡改行为，节点将**自动拒绝启动或立即终止运行**，确保被篡改的节点无法处理任何推理请求。

### 🔒 硬件级设备绑定

每台 DeepNode 节点在首次激活时，会与运行设备的硬件唯一标识进行绑定。凭证信息利用**操作系统级安全存储**（如 macOS Keychain）加密保存。这意味着：

- 凭证无法被复制到其他设备使用
- 即使拷贝了整个应用目录，在其他设备上也无法通过验证
- 每台设备的运行环境相互独立隔离

### 🔒 跨设备篡改检测

DeepNode 采用**设备专属标记机制**，为每台设备上的运行组件打上不可伪造的专属印记。如果有人试图将一台设备上修改过的文件复制到另一台设备，系统会立即识别并拒绝运行。即使攻击者精心构造"补丁包"，也无法跨设备传播。

### 🔒 系统级运行时防护

DeepNode 利用操作系统提供的**原生安全机制**（如 macOS Hardened Runtime），有效抵御以下高级攻击手段：

- 代码注入攻击
- 调试器附加攻击
- 内存读取攻击

### 🔒 平台级安全监控

DeepPool 平台持续监控每个节点的安全状态。当检测到节点存在以下异常时，平台将**自动封禁该节点**，停止向其分发推理任务：

- 完整性校验失败
- 设备绑定异常
- 其他可疑安全事件

被封禁的节点将无法再接收任何推理请求，最大程度保护 API 调用方的数据安全。

### 🔒 服务端版本准入控制

DeepPool 平台对接入的 DeepNode 实施**安全版本准入检查**。未经安全加固的旧版安装包在注册时会被平台**自动识别并拦截**，无法进入可用设备池。这确保了：

- 只有通过安全加固的 DeepNode 才能接入平台
- 旧版本安装包无法绕过安全机制为推理请求提供服务
- 平台运营者无需手动排查，系统自动执行准入策略

### 🔒 调度层安全隔离

即使某台设备的网络连接仍然在线，一旦被平台标记为异常（封禁或作弊），推理任务调度系统会**实时跳过该设备**，确保零推理流量分发到异常节点。封禁状态与调度系统实时联动，无需等待设备断线。

## 安全措施总结

| 防护层 | 能力 | 效果 |
|--------|------|------|
| 代码保护 | 编译保护 + 通信协议内置 | 无法直接读取或修改推理代码 |
| 完整性校验 | 启动校验 + 运行时持续校验 | 篡改后立即终止 |
| 设备绑定 | 硬件唯一标识 + 加密存储 | 凭证无法跨设备使用 |
| 跨设备防护 | 设备专属标记 + 文件级检测 | 补丁包无法跨设备传播 |
| 系统防护 | 操作系统原生安全机制 | 防注入 / 防调试 / 防内存读取 |
| 平台监控 | 实时安全状态上报 + 自动封禁 | 异常节点自动隔离 |
| 版本准入 | 服务端安全版本检查 | 未加固安装包无法接入 |
| 调度隔离 | 封禁状态与调度实时联动 | 异常设备零推理流量 |

## 算力提供者使用须知

由于上述安全机制的存在，DeepNode 在使用上有以下限制，请算力提供者注意：

### ⚠️ 不可跨设备复制

**已经在某台 Mac 上运行过的 DeepNode，不能直接复制到另一台 Mac 上使用。** 由于设备绑定和专属标记机制，复制后的 DeepNode 将无法通过安全验证，无法正常启动。

**正确做法**：在新设备上下载全新的安装包进行安装和激活。每台设备都需要独立完成首次激活流程。

### ⚠️ 禁止修改应用文件

请勿修改 DeepNode 安装目录下的任何文件。完整性校验机制会检测到修改并拒绝启动。如遇问题，请重新下载安装包。

### ⚠️ 凭证与设备绑定

设备凭证与硬件绑定，更换或重装硬件后可能需要重新激活。凭证存储在系统安全存储中，备份/迁移系统时无需手动处理凭证文件。

## 常见问题

**Q: 我的 Prompt 数据在 DeepNode 上安全吗？**

A: 是的。DeepNode 通过多层安全机制保护推理过程，节点运营者无法篡改推理代码以窃取 Prompt 数据。即使节点被物理控制，篡改行为也会被检测并阻断。

**Q: 如果节点运营者试图窃取数据会怎样？**

A: 任何对推理组件的篡改都会被完整性校验检测到。篡改后的节点将无法启动，即使绕过本地检查，平台也会自动封禁该节点，停止向其分发任务。

**Q: 我需要把 DeepNode 迁移到新 Mac，怎么做？**

A: 请在新设备上下载全新的 DeepNode 安装包进行安装。已激活的 DeepNode 无法通过复制方式迁移。

**Q: DeepNode 更新后需要重新激活吗？**

A: 通常不需要。常规更新会保留设备绑定信息。只有在全新安装或硬件更换的情况下才需要重新激活。
